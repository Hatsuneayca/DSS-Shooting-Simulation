# Legacy Scope Note

An earlier development iteration in this repository explored projectile-trajectory calculations and point-of-impact correction concepts. That implementation has been removed from the active branch because it does not match the current DASS research scope.

The current project is a modular device-management and training platform for dedicated inert, non-functional training props. Active development is limited to enclosure design, serviceability, power and device-health monitoring, local software, session records, verification, and product feasibility.

The earlier source revision remains part of the repository's Git history for provenance. It is not an active component, supported feature, validated model, or recommended use of DASS.
